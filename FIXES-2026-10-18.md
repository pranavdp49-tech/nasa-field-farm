# Field Shift frontend repair — 2026-10-18

## Root cause addressed
The overview dashboard passed `icon={Leaf}` to the candidate-rotations metric, but `Leaf` was not imported from `lucide-react`. That can raise a `ReferenceError` while React renders the first page, resulting in a blank dashboard.

## Additional guardrails
- Added `community: string` to the `ClimateData` TypeScript interface to match the backend response and avoid a frontend type-check failure when dependencies are installed.
- Added a React error boundary around the app. If a render-time exception recurs, the UI will display the exception message and a reload button instead of an empty page.
- Updated README troubleshooting steps.

## Verification in this environment
- TypeScript transpilation/syntax checks passed for App.tsx, main.tsx, api.ts and types.ts.
- A full `tsc -b` and frontend production build could not be verified because the React/Lucide/Vite npm packages are not installed in this environment and npm registry installation timed out.
- Install frontend dependencies on the target machine with `cd frontend && npm install`, then run `npm run build` and `npm run dev`.

## UI polish: light/dark themes

- Added an accessible top-bar theme control with Sun/Moon icons and a visible label on larger screens.
- Persists theme preference in `localStorage`; uses the system preference on the first visit.
- Added a dedicated `frontend/src/theme.css` theme layer for dark palette overrides.
- Switched the farm map to dark CARTO tiles in dark mode and adjusted marker contrast.
- Confirmed TSX transpilation syntax and CSS delimiter balance. Full frontend production build still requires npm dependencies to be installed locally.
